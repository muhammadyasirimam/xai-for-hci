# XAI for HCI — Explainable Loan Approval

An interactive demonstration of **Explainable AI techniques** applied to **Human–Computer Interaction (HCI)**.

## 🚀 Live Demo

👉 [Open Live Demo](https://muhammadyasirimam.github.io/xai-for-hci/)

## ✨ What This Demonstrates

| Technique | What It Shows | HCI Value |
|---|---|---|
| Local (SHAP-like) | Per-feature push toward approval/rejection | Users see *why* for *this specific case* |
| Global Importance | Which features matter most overall | Users learn the *model's general behavior* |
| Counterfactual | "What to change to flip the decision?" | Gives *actionable, concrete guidance* |
| Decision Path | Step-by-step model logic | Transparent reasoning; easier to trust |

## 🧠 HCI Design Principles

- Plain language explanations (no math jargon)
- Color coding (green/red) matches universal mental models
- Interactive sliders for "what if" exploration
- Progressive disclosure via tabs
- "How It Works" modal for full transparency

## 🛠 Tech Stack

- Vanilla HTML / CSS / JavaScript (zero dependencies)
- No backend, no API keys, no build tools

## 📂 Run Locally

1. Download or clone this repo
2. Open `index.html` in your browser
